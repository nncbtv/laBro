# Appunti Laboratorio Di Ricerca Operativa

Questa repository raccoglie il materiale prodotto durante il corso di Laboratorio Di Ricerca Operativa sviluppato man mano seguendo le varie lezioni

## A chi è utile?

Questo materiale è pensato per gli studenti che dovranno affrontare l'esame di Laboratorio Di Ricerca Operativa e vogliono un punto di partenza concreto per rivedere le parti principali del corso e confrontare lo svolgimento delle prove scritte.

## Struttura della Repository
### `Progetti_CPLEX/`
Contiene il codice sviluppato durante il corso e alcuni esercizi lasciati per casa
### `Appunti_Teoria/`
Contiene la spiegazione degli esercizi
### `Tracce_Svolte/`
Contiene la traccia e la relativa soluzione
